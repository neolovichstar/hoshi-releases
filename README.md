# Хоши — установщик для Windows

Здесь лежат только готовые установщики приложения «Хоши» — ИИ-компаньонки на рабочем столе.
Сайт: https://hoshi-desk.vercel.app

**Скачать последнюю версию:** [Hoshi-Setup.exe](https://github.com/neolovichstar/hoshi-releases/releases/latest/download/Hoshi-Setup.exe)

- Windows 10 и 11, 64 бит.
- Ставится в профиль пользователя, права администратора не нужны.
- Дальше приложение обновляется само.

Установщик пока без цифровой подписи: Windows может показать «Неизвестный издатель» — нажми «Подробнее» → «Выполнить в любом случае».
